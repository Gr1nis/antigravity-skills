# Чеклист и архитектура для Яндекс Игр (Unity WebGL / PluginYG / YG2)

Этот справочник подгружается при разработке и подготовке билда игры под платформу **Яндекс Игры (Yandex Games)**.

---

## 1. Главные требования модерации Яндекс Игр (на чем срезают 90% игр)

1. **Платформа и адаптивность (Desktop + Mobile Web):**
   * Игра обязана одинаково корректно работать и на ПК (мышь/клавиатура), и на мобильных браузерах (тач/свайпы).
   * Canvas Scaler: `UI Scale Mode = Scale With Screen Size`, `Reference Resolution = 1080x1920` (или `1920x1080`), `Screen Match Mode = Match Width Or Height (0.5)`.
   * Никаких кнопок «Выход из игры» (`Application.Quit()`) — в браузере они запрещены правилами модерации Яндекса!

2. **Звук при сворачивании вкладки и рекламе (Критично!):**
   * При показе полноэкранной рекламы (`Interstitial`) или видео за вознаграждение (`Rewarded`), а также при потере фокуса вкладки браузера (`OnApplicationFocus(false)` / `AudioListener.pause = true`) **весь звук игры и таймер должны ставиться на паузу**.
   * Разблокировка WebAudio: первый звук воспроизводится только после первого клика/тапа пользователя по экрану.

3. **Реклама и `GameplayAPI` (`GameReady`):**
   * Вызов `YandexGame.GameReadyAPI()` (или `YG2.GameReadyAPI()`) строго в момент, когда загрузочный экран скрыт и игрок может взаимодействовать с игрой.
   * Полноэкранная реклама (`FullscreenShow`) не чаще чем раз в **60–90 секунд** и только в логических паузах (переход между уровнями, рестарт), но **НЕ** в момент активного геймплея.
   * Перед показом межуровневой рекламы полезно выводить плашку с 2-секундным таймером («Реклама через 2... 1...»), чтобы избежать случайных мискликов (защита от отклонения по п. модерации).

4. **Размер WebGL-архива и скорость первого кадра:**
   * Целевой вес ZIP-архива: **до 15–20 МБ** (идеал для высокого конверта в запуск — до 10 МБ).
   * Настройки `Publishing Settings (WebGL)`:
     * `Compression Format`: **Brotli** (или **Gzip**, если тестируете локально; на серверах Яндекса Brotli поддерживается из коробки при включении `Decompression Fallback` или нативной отдаче).
     * `Enable Exceptions`: `Explicitly Thrown Exceptions Only` (или `None` для релиза — уменьшает размер WASM на 30%).
     * `Managed Stripping Level`: `Medium` или `High`.
     * Текстуры: сжатие `ASTC 6x6` / `8x8` или `Crunch Compression` (Quality 50–75), убрать MipMaps у всего UI.
     * Аудио: `Vorbis`, `Quality = 35-50%`, для фоновой музыки `Load Type = Streaming` или `Compressed in Memory`, `Force To Mono` для мобильных эффектов.

5. **Локализация и Облачные сохранения:**
   * Автоопределение языка через SDK (`YandexGame.EnvironmentData.language`: `ru`, `en`, `tr` — русский, английский и турецкий дают максимальный охват трафика Яндекса).
   * Сохранения через `YandexGame.savesData` (облако Яндекса) с дублированием в `LocalStorage` (`SaveManager.cs`), чтобы прогресс не терялся ни у гостей, ни у авторизованных игроков.
